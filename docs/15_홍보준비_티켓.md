# 코드 티켓

## M1 — 시세 0건 어종에서 가격 섹션 숨김
**근거(실측)**: `/fish/mineo` 가격 탭이 "최근 14일 · 0건 · 출처 0곳 · 수집된 시세가 없습니다"로 노출. 빈 선반은 신뢰를 깎는다. 데이터가 쌓이기 전까지는 없는 게 낫다.
**참고**: `FE/src/components/PriceSection.tsx` (`summary.observationCount`, `noDataReason`)
**프롬프트**:
> 상세 페이지에서 시세 관측이 0건인 어종(`noDataReason`이 있거나 `observationCount === 0`)은 가격 섹션과 해당 앵커 탭을 아예 렌더하지 않게 해줘. 히어로의 정적 가격대(₩ price_level)는 유지. 시세가 1건이라도 있으면 기존 UI 그대로. 부분 로딩/오류 상태(F4 계약)는 깨지 않기 — 숨김은 "성공 응답인데 0건"일 때만. 관련 컴포넌트 테스트 갱신.

**DoD**: 시세 없는 어종 상세에 빈 가격 섹션·탭 미노출, 시세 있는 어종은 기존과 동일, 테스트 통과.

## M2 — 제철 캘린더 월별 URL 딥링크 + prerender/sitemap
**근거(실측)**: `FE/src/pages/CalendarPage.tsx`의 `selectedMonth`가 컴포넌트 state라 "11월 제철 회" 검색·공유 랜딩이 불가능. 월별 URL 12개는 그대로 SEO 랜딩 12개다.
**참고**: `FE/scripts/prerender.mjs` (`fixedPaths`에 `/calendar` 존재, build-time sitemap), docs/13 F6
**프롬프트**:
> 제철 캘린더를 `/calendar/:month`(1~12) 경로로 딥링크 가능하게 해줘. `/calendar`는 현재 월로 동작(리다이렉트 대신 렌더 후 URL 정규화 무방). 월 버튼 클릭 시 URL 변경(replace), 직접 진입·뒤로가기 자연스럽게. 범위 밖 month는 `/calendar`로 폴백. `document.title`과 meta description을 "N월 제철 회·횟감" 형태로 월별 반영. prerender `fixedPaths`에 12개 월 경로를 추가하고 sitemap에도 포함, canonical은 각 월 URL. CalendarPage 테스트에 라우팅 케이스 추가.

**DoD**: `/calendar/11` 직접 진입·공유 동작, 12개 월 페이지 prerender+sitemap 반영, 월별 title/OG 노출.

## M3 — 대표·OG 이미지 자체 호스팅 이관 (핫링크 제거)
**근거(실측)**: 로컬 이미지는 `FE/public/fish/` 4종(광어·방어·연어·참돔)뿐, 나머지 22종은 카드·상세·`og:image`가 nifs.go.kr 원본 핫링크. 첫 로딩이 눈에 띄게 느리고, 커뮤니티 홍보로 트래픽이 몰리면 외부 사이트에 부하를 전가하게 된다(장기 지속성 리스크는 BACKLOG 4.5에 기인지).
**참고**: `config/fish_image_manifest.json`(alt·credit·license·원본 URL·focal point 보유), Cloudinary 파이프라인(후기 업로드에서 기사용)
**프롬프트**:
> `config/fish_image_manifest.json`의 26종 원본 이미지를 Cloudinary(또는 `FE/public/fish/` 정적 자산)로 이관하는 스크립트를 `scripts/`에 만들어줘. 이관 후 FE 카드·상세·prerender OG가 자체 URL(f_auto,q_auto + 용도별 width 변환)을 쓰도록 seed/manifest를 갱신하고, 원본 URL·라이선스·credit은 manifest에 보존한다. 공공누리 출처표시 의무에 맞게 화면의 "사진: 국립수산과학원" 캡션은 유지. 홈 히어로·기본 OG 폴백도 자체 자산 확인.

**DoD**: 26종 카드/상세/OG 이미지가 자체 도메인·CDN에서 서빙(nifs 핫링크 0건), 출처 캡션 유지, 카드 첫 로딩 체감 개선.

# 콘텐츠·운영 티켓

## M4 — 회(음식) 사진 보강 — 인기 4종부터
**근거(실측)**: 전 어종이 표본(원물) 사진뿐. 도감 정체성엔 맞지만 "먹기 직전 결정" 사용자에게 식욕 훅이 없다. 입문자 채널(인스타·커뮤니티) 홍보의 선행 조건.
**원칙**: 직접 촬영 최우선(횟집·시장 방문 시 축적), 아니면 라이선스 확인된 공개 소스만(docs/08 부록 A). 출처 불명 사진 금지. manifest에 license/credit 기록.
**범위**: 1차 = 홈 "바로 찾아보기" 4종(광어·방어·연어·참돔) 각 회 사진 1장. 이후 제철 도래 순(전어 9월 → 방어 11월)으로 확대.
**적용 위치**: 카드 대표는 표본 유지(도감 정체성), 상세 갤러리(`fish_image`, 기존 B2 다중 이미지 지원) 첫 장을 회 사진으로, **OG 이미지는 회 사진으로 교체**(공유 클릭률).

**DoD**: 4종 상세 갤러리에 음식 사진 노출, 해당 4종 OG 교체, manifest에 라이선스 기록.

## M5 — 후기 콜드스타트 해소 (실경험 기반)

**원칙**: **허위 후기 금지.** 실제로 먹어 본 경험만, 본인·지인이 각자 닉네임으로 작성. 사진 첨부 우선(후기 사진 업로드 기구현).
**목표**: 인기·제철 8종+ 에 각 1개 이상, 총 10~15개. 이후 커뮤니티 유입 사용자가 "첫 후기"가 아니게 유지.
